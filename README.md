# Spring Boot Grid Game

## Sobre o Projeto

O **Spring Boot Grid Game** é uma reconstrução de um mini game que desenvolvi há alguns anos utilizando apenas **HTML, CSS e JavaScript**. Na versão original, o jogo era executado localmente e possuía apenas um jogador.

O objetivo deste projeto é recriar o jogo utilizando tecnologias mais robustas e modernas, aplicando conceitos avançados de desenvolvimento back-end e arquitetura de software para aprimorar meus conhecimentos em desenvolvimento Java.

Além de reproduzir as funcionalidades da versão original, esta nova implementação adiciona recursos inéditos, melhor organização do código e uma arquitetura preparada para múltiplos jogadores.

## Objetivos

- Recriar um projeto antigo utilizando tecnologias modernas.
- Praticar desenvolvimento back-end com Java e Spring Boot.
- Implementar comunicação em tempo real utilizando WebSocket.
- Aplicar boas práticas de arquitetura e organização de código.
- Desenvolver funcionalidades multiplayer.
- Aprimorar conhecimentos em sistemas cliente-servidor.

## Funcionalidades

- Criação e gerenciamento de mapas.
- Movimentação de jogadores em uma grade (grid).
- Comunicação em tempo real utilizando WebSocket.
- Sincronização de eventos entre cliente e servidor.
- Estrutura preparada para múltiplos jogadores.
- Sistema de regras centralizado no servidor.
- Persistência e gerenciamento de dados do jogo.

## Arquitetura

O projeto segue uma arquitetura cliente-servidor, onde:

- O servidor Spring Boot é responsável pelas regras do jogo.
- Os clientes se conectam através de WebSocket.
- As ações dos jogadores são processadas no servidor.
- O estado do jogo é sincronizado em tempo real para todos os clientes conectados.

## Motivação

Este projeto surgiu da vontade de revisitar um dos primeiros jogos que desenvolvi e reconstruí-lo utilizando conhecimentos adquiridos ao longo dos anos.

Mais do que reproduzir o jogo original, o objetivo é utilizá-lo como laboratório de estudos para explorar conceitos como:

- WebSocket
- Programação orientada a objetos
- Arquitetura cliente-servidor
- Gerenciamento de estado
- Estruturas de dados
- Desenvolvimento de jogos multiplayer
- Boas práticas com Spring Boot
